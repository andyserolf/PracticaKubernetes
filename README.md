## ?? Organización del Repositorio
* \/frontend\: Código fuente e interfaz ligera de usuario (Dockerized).
* \/backend\: API REST modular (Python/FastAPI o Node.js/Express).
* \/desarrollo\: Manifiestos de Kubernetes para el entorno de Desarrollo (Clúster Mononodo).
* \/produccion\: Manifiestos de Kubernetes para el entorno de Producción (Clúster Multinodo, HPA).
* \/red\: Configuración de CNI, NetworkPolicies y Firewall.
* \/observabilidad\: Prometheus, Grafana, Exporters y Alertas.
* \/respaldos\: Scripts de backup/restore para PostgreSQL y MongoDB.
* \/documentacion\:
  * \/expediente\: Expediente técnico completo con los documentos D01 al D10.
  * \/evidencias\: Capturas, logs y archivos de métricas (E01 a E14).
